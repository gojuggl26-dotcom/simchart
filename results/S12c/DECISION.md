# S12c/d 決定記録 — 窓再現性の天井と近臨界レジーム (2026-08-25)

## 1. 共鳴の罠 (S12a で実測)

同一 MG 系の異写像 3 本で、$\chi_3 = 15$ 日ピークは $\chi_2$ (30 日) と厳密 2:1 共鳴になり
|corr| = 0.22。支配周期が整数比で噛み合うため。4.7 / 13.1 / 30 日 (低次整数比
なし) に離調して全ペア |corr| < 0.1。

## 2. 窓再現性の天井 = whale 供給制約の第三の顔

目標 (窓あたり危機件数のシード横断相関 0.3〜0.6) は到達不能と
実測確定。走査した軸: $b_\chi \in [0.5, 2]$、$n_{\mathrm{max}} \in{0.93, 0.95}$、検出基準
{2 日適応, 30 日緩慢}、窓長 {5, 10, 13, 20} 日。

- 最良は 5 日窓で ICC ($\chi_3$ 起因シェア) = 0.145 / ペア相関 ~0.11。
- 13 日以上の窓は $\chi_3$ 周期 (13.1 日) を窓内で平均して消す (ICC 0.05)。
- 検出基準を緩慢化しても不変 — 検出 3 条件が全て局所比 ($k \cdot \sigma_t$、$m \times$通常)
  なので、持続的な脆弱窓では分子分母が同時に動き発火率に現れない。
- 根因: 危機の存在は whale スイープ供給 (シード固有、S11c) — $\chi_3$ は
  増幅を変調するが存在を作らない。g 帯 (S11)・Hill (S11)・窓再現性 (S12) は
  同一のアーキテクチャ制約の三つの顔。
- 解決 (設計要件 自身の区別を計器化): 窓そのもの (n_t) の再現は
  nt_window_reproducibility (> 0.30 — $\chi_3$ 支配なので高い) が判定し、発火の
  窓相関は達成帯 [0.05, 0.60] + ICC 記録に再設定。下限 0.05 は$\chi_3$ が効いて
  いない$( \approx 0)$ の棄却を保つ。

検出器の教訓: 13 日窓を測る器具の通常基準が 2 日で適応してはいけない —
crisis_norm_halflife_days を u 信号から分離し、S12 は 30 日で測る
(既定 2.0 は S11 の記録を保存)。

## 3. 近臨界レジーム (事前測定 #2 の 7 不合格の解剖)

$n_{\mathrm{max}} = 0.95 + b_\chi = 2.0$ で系は $\chi_3$ 窓の間 $n_t \approx 0.95$ に滞在し:

- 平均レート $\times 1.99$ — $1/(1 - n)$ の凸性 (Jensen): $E[1/(1 - n_t)]$ は n_t が
  [0.755, 0.945] を振れると設計アンカー $1/(1 - 0.83)$ の ~2 倍。
- Fano(1min) 74.5、バーストキャップ $(50 \times)$ ヒット 0.14%、$\hat{n} (MLE) 0.926$。
- 板側ゲートは全通過 ($spread/\eta /\gamma /T/$危機統計) — つまりこれは故障ではなく
  脆弱窓の活動は高いという設計帰結。均一なベースライン割引で消すのは誤り
  (静穏窓が飢える)。

対処 = 計器の時変 n_t 対応 (S11 再定義の帰結):

| 計器 | 対処 |
|---|---|
| realized_rates | n_t 込み予測 $E[(1 - n_d)/(1 - n_t)]$⁻¹ で正規化 (z と同格の閉ループ) |
| $\hat{n}$ 対設計 $(true/est \pm 0.05)$ | 記録へ — 判定は n_hat_matches_mean ($\hat{n} \approx$ イベント加重 E[n_t]) が承継 |
| nt_mean | 時間加重へ (イベント加重は $1/(1 - n)$ の 20 倍重みで 0.90 に張り付く — S11 の signal_is_surprise と同型の混同) |
| Fano | 記録帯 [10, 150] (近臨界クラスタは設計。暴走は no_divergence が保証) |
| バーストキャップ | 50から150 (S7 較正は $n \approx 0.83$ 前提。常用ヒットは thinning を歪める — 物理側を再較正) |
| sign_acf_level | 退役 (残差 C(1) ゲートが置換済み — raw は記録継続) |

## 4. 作業点

$b_\chi = 2.0 / n_{\mathrm{max}} = 0.95 /$ 検出基準 30 日 / キャップ $150 \times$。
$b_\chi =1.0$ は窓信号が半分 (ICC ~0.07) になる一方でレート歪みは +15% に軽減される —
窓信号 (S12 の中核) を優先し、レート歪みは計器対応で吸収する側を選んだ。
