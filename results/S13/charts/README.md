## 日足の作り方

1. **日中**: 板のミッド (観測) を 1 秒刻みで見て OHLC を取る。高値・安値は
   終値だけからは復元できない量なので、日中経路を実際に見ている証拠になる。
2. **日境界**: S4 のオーバーナイト・ギャップを累積合成する。`log_p_star` も
   観測系列も日中のみの連続経路で、ギャップは別配列に分離されている
   (本プロジェクトの規約: 「クローズ・トゥ・クローズ系列は検証側で合成して作る」)。
   **合成しないと日次分散の 20% がチャートから消える** (実測 ON シェア 15.9%)。
3. **出来高**: 板の集約約定から日次合計。S6 以降は注文流が内生的に決まるので
   実データとして書ける (S0 では「注文流が無いので出来高は捏造」だった)。
4. **板ウォームアップ 5 日を除外**。板は `init_levels=30 × init_size=20` の
   人工的に厚い状態から始まり、`book_burn_in_days` かけて定常に達する。
   残すと 100 本すべての冒頭が一様に不自然に穏やかになる → 495 営業日 (約 2 年)。

## ★既知の注意点 (使う前に読むこと)

### 1. 板ミッドの暴走と品質選別

**L2 (情報価格 p*) は設計どおり健全だが、板の追随が壊れる本がある。**
最悪例 (選別で除外済み): 潜在が −0.67% の日に観測が **−60.9%**。

伝達比 T = Var(観測日次)/Var(潜在日次) で選別した (閾値 **2.534** =
S12 本番 24 シードで実測された増幅の最大値 `fb_rv_excess_ari`。恣意的な
丸い数字ではなくタグ済み本番で実際に起きた水準を上限にしている)。
**選別で 12 本除外**、採用 100 本の T は中央値 1.19 / p95 1.91 / 最大 2.35。

暴走は**流動性 (実効アンカー束 κ·μ) で決まる**: 資産 1 (κ·μ が参照の 3 倍) は
T 中央値 1.04・最大 1.6 で全数健全。窓逸脱で落ちる実行 (5/43 = 12%) は
この現象の極端側にすぎず、**「窓に収まった = 健全」ではない。**

**★伝達比は分散全体で見るので、1 日だけ飛んで翌日戻る単発スパイクは
捕まらない。** `max_abs_daily_return` 列で追加選別できる (潜在の最大は
実測 9.1%):

| 条件 | 本数 | 年率ボラ中央値 | T 中央値 |
|---|---|---|---|
| 全採用 (T < 2.534) | 100 | 0.234 | 1.19 |
| **max\|r\| ≤ 15%** | **82** | **0.2221** (σ̄ と一致) | **1.11** |

厳密さが要る用途 (裾の推定・リスク指標の較正) では **82 本のサブセット**を
推奨する。見た目の多様性が欲しい用途では 100 本すべて使ってよい。

### 2. 日次リターンの負の自己相関 (−0.045)

板ミッドが p* へ引き戻される乖離の平均回帰 (乖離系列の ACF(1) = −0.19、
S10 で測った乖離半減期 277 分と整合) が出所。日中のみのリターンでも
−0.048 なのでギャップ合成のせいではない。実市場の短期反転
(−0.02〜−0.05) と同程度だが、**機構は実市場と異なる**ことに注意。

### 3. `realized_vol_annualized` 列は日次リターンの SD と一致しない

この列は **5 分リターンからの日次実現ボラ**で、中央値 0.034 (年率)。
日中リターンの RMS (年率 0.197) の 0.56 倍しかない。これは計算バグではなく
(5 分と 1 秒の実現分散が一致することを検算済み)、**日内の超拡散** —
メタオーダーの符号相関で価格が同方向に押され続ける、S8 以来の既知の未達
(README の「約定時間 VR」「√ 則」と同根) の現れ。
**日次のボラが欲しいなら `annualized_vol_cc` を使うこと。**

### 4. マルチンゲール性は 100 本では判定できない

E[P_T/P_0] = 1.149 (z = +5.0) だが、**潜在 p* でも同じ** (1.139, z = +5.0)
なので板の問題ではない。原因は (a) 終端グロスリターンが上位数本に支配される
(裾 α≈3。上位 3 本を除くと 1.123)、(b) **χ₁/χ₂/χ₃ は全シードで共有される
決定論系列**なので、「1 つの χ 実現」に条件づけられた標本になり、シードを
増やしても相殺されない。S0 の同種の検証が 1000 本を使い、かつ χ の無い段階で
行われていたのはこのため。**この標本でボラ正規化を検証するなら
`vol.ensemble` (アンサンブル断面 20 万本、S1 以降の本番で合格) を見ること。**
