## 構造的発見 (ゲート再設計の根拠)

1. **追跡速度の天井**: 半減期は κ→∞ でも ~170 分で飽和する。閉じる速度 =
   指向フロー × 子 1 本のインパクト ≈ ψ·1800/日 × 0.24bp ≈ 430bp/日 が上限で、
   σ の流入 126bp/√日 との均衡が d SD ~30-40bp・HL ~3h を決める。tanh は
   κ≥1 で既に飽和 (equilibrium d/s ~ 2)。指示書 §4.1 の「数分〜数十分」は
   この流量・インパクト規模では到達不能。実市場の「分単位の情報織り込み」は
   気配の再提示 (フローなしの価格改定) が担うが、本モデルの結合チャネルは
   成行符号のみ (仕様どおり)。
2. **raw γ̂ の低下 (0.61→0.33) は消滅ではなく情報チャネルの重畳**:
   C(ℓ) は d 緩和スケール (ℓ~30-1000) に「追跡ハーディングのこぶ」を持ち、
   その先で負帰還により切断される。**生成時バイアス E[ε|d]=tanh(κd/s) を引いた
   残差符号の γ̂ = 0.611 = S8 の 0.614** — 分割構造 (⑪ の機構) は完全に無傷。
3. **R(ℓ) は κ>0 で初めて飽和する** (S8/S9 は線形成長)。ただし飽和スケール
   ℓ* ~ 1000-3000 約定 (= HL×レート)。S8 規約のフィット窓 (5-150) は ℓ* の
   内側なので β̂=−0.47 に見える。長窓 (30-2000) で β̂=−0.10 — 減衰は物理の
   いるスケールに存在するが、(1−γ)/2 ± 0.05 には届かない (ℓ* が実市場の
   ~数十約定より 1.5 桁遅いため)。
4. **恒久インパクトの傾き ≈ 0**: 実行終了 +1000 約定後のインパクトは N と
   ほぼ独立 (傾き +0.04)。恒久成分 = 生成時の情報 (d) の織り込みであり、
   長さ N は独立に抽選されるため。**√法則 (0.4-0.7) の経済学 =「大口ほど
   情報が多い」という Q と情報の内生相関が、この生成モデルに存在しない**。
   ピーク規約は 1.02 (子数比例のまま)。
5. **エスカレーション §10-3 (L3 流動性) の見送り**: 板を薄くしても速度は
   ~2-3× (必要 ~15×)、かつ α_LO 変更は S7 Hawkes の μ=(I−aᵀ)r 較正・S6/S9 の
   全帯を連鎖的に壊す。費用対効果で不採用 — 本ファイルと README に記録。
