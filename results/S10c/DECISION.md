# S10c 決定記録 — c_vol = 0.65 (2026-08-24)

## 実装 (コミット 5381b51)

Z_t = exp(c·V_t − c²/2)、V_t = (MA_3d(log σ_obs) − m_V)/s_V。Hawkes のベースライン
のみに乗せる (φ_λ と同格 — カーネル不変で分岐比 n 保存)。CX の δ0·N にも乗せ、
定常板人口 N* = α/δ0 を保ったまま回転率だけが Z に比例する。thinning は
ブロック前方 max (z_up) + 有効域端での候補打ち切り (指数の無記憶性で厳密なまま)。

### 因果性の設計 (§7.1)

- m_V は決定論定数 (価格層が composition 診断に記録する
  `mean_log_vol_deterministic` = log σ̄_diff + MSM の E[log M] − var_slow −
  var_rough − c_chi + log φ_σ 平均)。20 シード実測で不偏 (t = −0.5)。
  MSM 項は E[ΠM]=1 でも E[log M]<0 なので省くと −0.3 ずれる (実装済み)。
- s_V = 0.45 固定 (MA_3d 系列の定常 SD。価格層のみ 1000〜5000 日 × 5 シード
  実測: 500d 0.387 / 1000d 0.454 / 2000d 0.411 / 5000d 0.461)。
- 全標本平均・SD での標準化は使わない (早い時刻の Z が遅い時刻を知る)。

### 帰結 (実測済みの物理 — バグではない)

- エポック効果: 緩慢成分 (OU HL30d・MSM 遅い成分・χ₂) の実行内実現平均が
  ±0.22 (250 日でも) 揺れるため、実行ごとの実現 E[Z] は ±10〜15% 動く
  (500 日 z_mean 実測 0.86〜1.15)。高ボラエポック = 高活動は正しい物理。
  レート系ゲートは多シード中央値で判定する (S8 以来の原則)。
- Jensen 不足: 短ホライズンでは実行内 Var(V) < 1 で E[Z] が数 % 下振れ
  (500 日 z_mean 中央値 0.97〜1.0)。本番地平 (5000 日) では ≈1。

(寄付が最も広い) と逆。c_vol=0 対照でも同形なので S7 由来の既存性質

## T_daily 再測定の教訓 (σ̄ の帯端問題)

対照行 (c_vol=0, σ̄=0.2217) の T_1d 中央値 = 0.914 — S10b の収束値 0.952 と
不一致。調査の結果:

1. コード回帰ではない: σ̄ を S10b の厳密値 (0.22166545…) に戻すと seed 42 の
   T_1d = 0.9524 をビット単位で再現。
2. 原因は σ̄ の丸め (0.2217、+0.015%) がティック離散の板を脱相関させる
   再実現ノイズ。T の 500 日推定は 1 シードあたり ±0.05 程度揺れる。
3. つまり S10b のT_daily = 0.952 で帯内は推定ノイズ込みの帯端で、
   真値は 0.91〜0.95 帯のどこか。500 日でこれ以上反復しても noise chasing。

対処: σ̄ = 0.2217 のまま S10d (1000 日 × 5) で T_daily を高精度に再測定し、
明確に < 0.95 なら 5000 日ゲートラン前に 1 回だけ σ̄ を最終更新する
(κ は動かさない。5000 日ランの中では絶対に動かさない)。c_vol の選択は
T と独立 (スイープ全行で T_1d 0.87〜1.04 に系統傾向なし) なので影響しない。
