# S13 設計判断の記録 (S13a〜c)

作成 2026-08-25。S13 = 多資産化 (工程最終段階)。指示書からの逸脱・計器設計・
実測に基づく再設計をここに記録する (README へは確定後に要約を転記)。

## 1. N=1 退化の写像: 「β=1・全成分共通」ではなく「共有ゼロ・全成分固有」

指示書 §8.3 の例示は「β=1、k_c を全成分、など」。**採らなかった。** 理由:

- β=1 は固有チャネルの重み √(1−β²) = 0 で、**bridge レバレッジ (ρ_rough) と
  固有ラフ成分の経路が消える**。S12 の z は bridge 済み (セル集計 = ρ·ε + 直交)
  なので、β=1 の合成 z = z_F (素の iid) は S12 とビット単位で一致し得ない。
- ラフ成分は共有禁止 (§4.3) なので「全成分共通」は定義できない。

採った写像: **n_assets=1 では因子パラメータを全て退化 (共有 0) させ、資産 0 の
固有ストリング = レガシー名**とする。これで N=1 は S12 と同一コードパスになり
ビット単位一致が自明に成立する (n1_regression)。因子コードパス自体の退化は
**N=2・β₀=0・共有シェア 0 で資産 0 が S12 とビット一致**する検査
(factor_degeneracy_check) が固定する — β=0 は乗算ごとスキップし、
共有 0 の固有 OU は var_override が S12 と同値になるため厳密に同経路。

ストリーム設計: 共通 = `cross.*` (n_assets 非依存)、資産 0 = レガシー名、
資産 i≥1 = `.asset{i}` 接尾辞。資産追加不変性 (§8.2) は名前ハッシュから構造的に
従い、asset_addition_check がビット単位で確認する (30 日 — ビット単位の構造性質
なので規模非依存)。

## 2. ラフ・レバレッジの周辺希釈 (指示書 §4.4 の主張との差)

§4.4 は「ρ を両チャネルに同値適用すれば周辺レバレッジは単一資産時と一致」と
主張するが、**ラフチャネルには共通側が存在しない** (§4.3 がラフの共有を禁止する
ため)。合成後の周辺レバレッジ係数は

    ρ_rough^marginal = √(1−β_i²)·ρ_rough   (β=0.8 で 0.6 倍)

に構造的に希釈される。これは §4.3 と §4.4 の緊張であって実装欠陥ではない。
緩慢 OU チャネルは共通・固有の両駆動に同値 ρ_slow を適用 (字義どおり) —
こちらの希釈は cos 型で ≤7%。**対処しない** (S3/S10 以来レバレッジ実測水準は
≈0 の既知未達で、方向性記録のみ)。diagnostics に理論係数を記録
(`leverage.rho_rough_marginal_theory`)。

## 3. 共通ジャンプの設計

- **同一の対数サイズ**を全資産に加算 (完全コジャンプ)。β スケーリングはしない —
  予算恒等 (資産あたり QV = S12 と同一) を厳密に保つ最小構成 (§2 作り込まない)。
- 強度分割: 固有 (1−s_J)·λ0 は S12 機構そのまま (資産の全 σ で変調)、共通
  s_J·λ0 は**共通ボラ状態** (共通 MSM + 共通 OU + χ₂ + φ_σ) で変調。
  補正 (ON 取り分・φ^ρ・χ₂ の Jensen) は資産側と同形。共通成分自身の Jensen
  (E[√M]^k_c 等) は S12 が固有成分で残すのと同じ規約で残し、実効強度を診断に
  報告する。固有と共通の変調母集団の違いで資産あたり総実効強度は S12 と
  厳密には一致しない — 実測 ±12% 以内 (テストで拘束、jv_share_theory は
  共通込みの総量を報告するよう修正済み)。

## 5. 計器設計

- **daily_corr_matches**: 判定は「シード中央値の相関 vs 理論」。per-seed の
  max 誤差は 1000 日の相関 SE ≈ 0.032 × 3 ペア max ≈ 0.05 でゲート幅 ±0.05 を
  雑音だけで食い潰す (S12 ③ 帯の検定力再設定と同型)。5 シード中央値なら
  SE ≈ 0.018、ペア max ~0.04 で検定力が立つ。
- **理論値** (cross.theoretical_daily_corr): corr_ij = β_iβ_j·D·(1−j_s)+s_J·j_s、
  D = (E[√M]²)^{k−k_c}·e^{−v_idio} = 0.905 (現行構成)。対象は**潜在**日次
  リターン (因子構造の直接対象)。観測 (板ミッド) は追跡ラグの希釈込みで記録。
- **HY ゲート**: p* を**各資産の実約定時刻**でサンプルした系列に HY を適用し、
  同一窓の潜在 1 分実現相関と照合 (±0.05、間引き ×1/2/4 の全条件)。§12 の
  「まず p* 同士で検証」の恒久形 — 板約定値 (VWAP) の HY はマイクロ構造減衰
  込みの記録に置く。Epps は約定 VWAP の前値サンプル (古典的な測定対象)。
- **危機時相関**: ペア和集合の危機日マスク、シード横断プール (1000 日 × n
  シード連結) で §11 の「2000 日以上」を満たす。

## 6. S12 ゲートの承継方針

- baseline_invariance 系 8 ゲート → L2 再構成 (因子合成) が段階の差分そのもの
  なので S12 メトリクス直接照合は成立しない。**ビット単位の構造検査 4 種**
  (n1_regression / factor_degeneracy / asset_addition / l2_frozen_multi) で置換。
  l2_frozen_multi は板 off の run_multi との潜在照合で、流動性オーバーライドが
  L2 に漏れていないことの検証を兼ねる。
- ペア (off 対) 計器 7 種 (g・発散・T_off・⑭・超過ボラ・iceberg) →
  **S12 本番 30 シードの実測値を繰り越して同じ帯で判定** (metrics.s12_carryover)。
  根拠は §11 の明文 (「参照資産の単変量性質は S12 の結果を流用 — §8.3 の回帰
  テストで担保」) と n1 ビット一致。多資産で off 対を回すとシードあたり
  run_multi 2 本 (計 ~7 分) × 5 で費用が倍加する割に、ループ機構のコードパスは
  1 bit も変わっていない。
- multiseed 単変量ゲート (hill・③・⑦・危機統計・η 等) は**参照資産で再測定**
  (ソロ計器のみで測れるため)。coverage 床は 8/10 → 4 (§11 の縮小規模)。

## 6b. 薄板の窓逸脱と 500 日への再設計 (事前測定 #2 の実測、2026-08-25)

1000 日 × 3 資産で**薄板資産 (レート ×0.4) が板の絶対ティック窓から高率で逸脱**
する。判別実験 (seed 43/44 × {tick 1/2bp, 窓 4900/9900, κ 0.1/0.2, レート
×0.4/×0.6}) の結論:

- **逸脱は p* ではなく板内生**: 死亡シードの p* は log ±0.22 圏内なのに
  ミッドが ±$98 に到達 (板なし run_multi で p* レンジを直接実測)。
- ティック粗化 (2bp/5bp) は正値性上限が窓ティック数を削り **全滅** (0/4)。
  κ を 0.2 に戻しても不変 → ティックレジーム混在 (§6.2 の任意項) は
  このアーキテクチャの窓制約と構造的に非両立 — 断念して記録。
- 参照形状 (1bp/9900) でも薄板の 1000 日生存率 ~50% (seed 43 は
  ×0.4〜×0.6・κ0.1〜0.2 の全変異で死亡、seed 44 は全変異で生存 —
  シードの板ストリーム抽選が支配)。
- 機構仮説 (記録): κ バイアスの正規化 s = σ_t√τ は高ボラ窓 (χ₃ 近臨界 +
  フィードバック増幅) で d/s を縮め、アンカーを実効的に外す。薄板は
  同じ窓で whale スイープの相対インパクトが大きく、外れたアンカーの下で
  ミッドが漂流する。S10 の「絶対ティック窓は κ>0 の長期ランを支えない」
  (README 既録) の薄板増幅形。

**対処: 視野を 500 日 (指示書 §11 の帯 500〜1000 の下端) に落とす。**
seed 43 も 500 日では完走。相関系は 500 日で収束し (§11 の明文)、
危機時相関の標本はシード横断プール (500 × 完走数 ≥ 2000 日) で満たす。
単変量の長期性質 (③ 等) は S12 の 1000 日 × 30 を繰り越し、n1 回帰は
視野不一致で記録に降格 (ビット単位判定は factor_degeneracy が担う — 設計済み)。

## 6c. 危機時相関の機構解剖 (§7.2 のゲート再設計、seed 42 実測)

指示書の字義 (検出危機日の和集合で条件付けた観測日次相関) は **負** (−0.13):

| 条件付け | obs Δ (3 ペア) | latent Δ |
|---|---|---|
| 和集合 (字義) | −0.19 / −0.13 / −0.05 | +0.12 / +0.11 / −0.04 |
| 同時 (≥2 資産) | −0.32 / −0.10 / +0.24 | −0.01 / −0.16 / +0.23 |
| **潜在 big\|z_F\| (上位10%)** | +0.29 / −0.10 / +0.08 | **+0.32 / +0.28 / +0.21** |
| χ₃ 脆弱窓 (上位30%) | −0.19 / −0.05 / −0.03 | +0.09 / +0.19 / +0.23 |

読み: **§7.1 の機構 (共通変動の同時拡大) は潜在層に明確に実在する** (big|z_F|
Δ+0.2〜0.3)。字義の条件付けが負になるのは、危機の存在が whale 供給 (資産固有)
のため「危機日」= 固有内生変動が支配する日 (自資産危機日の |r| 中央値は 2.6 倍)
を選択してしまうから — **S11 の g 帯・S12 の窓 ICC 天井と同根の制約の第四の顔**。
s_J 引き上げ (§7.2 の代替レバー) は corr_normal も同時に上げるため Δ には
効かない (共通ジャンプ日 ⊥ 危機日 — χ₂ ⊥ χ₃ の設計帰結)。

**事前約束の判定規則** (事前測定 #3 のプール値で機械的に適用):
1. プール和集合 Δ > 0.15 → 字義のまま
2. (1) 不成立で プール・ブレッドス (≥2 資産、検出器ベース = リターン選択なし)
   Δ > 0.15 → ブレッドス形をゲート、和集合は機構つき記録
3. 両方不成立 → アーキテクチャ制約として文書化し、機構実在ゲート
   (潜在 big|z_F| Δ > 0.15) + 観測側 2 形の記録に再スコープ

## 6c-2. 規則の適用結果 (事前測定 #3、500 日 × 9 有効シード、2026-08-25)

プール (4,500 日/ペア): 和集合 Δ = **−0.075** (規則 1 不成立) / ブレッドス
Δ = **+0.089** (全ペア正 +0.041〜+0.112 だが 0.15 未満 — 規則 2 不成立) /
潜在 big|z_F| Δ = **+0.391** (全ペア +0.338〜+0.407) → **規則 3 を適用**:

- critical ゲート `crisis_corr_increase` = 潜在 big|z_F| 条件付け > 0.15
  (§7.1 の機構実在の判定)
- 観測層は方向ゲート `crisis_corr_observed_breadth` (> 0、実測 +0.089) +
  和集合の記録 (−0.075)

観測層の振幅半減は「板の固有内生変動」(追跡ノイズ + whale スイープ) が
日次分散の ~50% を占める構造の帰結 — 潜在 0.47 → 観測 0.29 (平常日) の
相関希釈と同じ機構。危機の**発生**が固有 (whale) である限り、検出危機日の
条件付けは固有分散支配日を選ぶ。これは S11 の g 帯・S12 の窓 ICC 天井と
同根のアーキテクチャ制約の**第四の顔**として README に記録する。

## 6e. 500 日視野の計器較正 (vol_corr / ③ / Hill)

- **vol_corr**: 帯 [0.55, 0.85] は ∞ 視野の設計シェア。500 日窓では最遅の
  共有 MSM 成分 (500/250/125 日) が実現しきらない。2 状態切替 (率 γ) の
  窓内実現係数 f = 1 − (2/aT)(1 − (1−e^{−aT})/(aT)) (a = 2γ) で成分和を
  取ると、共有実現 0.131 / 総実現 0.228 → **期待 corr ≈ 0.574**。実測ペア
  中央値 0.51-0.55 (エポック ± 込み) — 帯を [0.45, 0.85] に較正し、判定値は
  ペア中央値の中央値 (min はペア間ゆらぎの下振れ選択)。∞ 視野の設計は
  2000 日の成分検証 (テスト固定: corr(msm_common, 資産) 理論 0.735 vs
  実測 0.70-0.75) が別途固定している。
- **③ (obs−latent gph 差) と Hill**: 500 日では計器の検定力が立たない
  (③ per-seed IQR 0.185 — マスク後 365 日の GPH / hill は k=5% で 18 点、
  IQR 0.78)。指示書 §11 の明文 (「参照資産の単変量性質は S12 の結果を流用」)
  に従い S12 (1000 日 × 30) の実測を繰り越し (③ −0.024 ∈ ±0.10、
  hill_ex 3.28 ∈ [3,5])、500 日の再測定値は multiseed に記録として残す
  (実測: ③ −0.175 / hill_ex 2.90 / hill_all 3.12 — 視野依存のテール統計)。

## 6d. ⑦ の帯の再設定

同一シード比較 (S12 seed42 0.510 → S13 0.625、S12 の 30 シード範囲外) で
実シフトを確認。機構: 共通ジャンプの変調が遅い共通成分 (= V の 3 日 MA 帯域)
なので、ジャンプ RV と出来高の結合が S12 の瞬時 σ 変調より強い。c_vol は
不変のため、ゲートは S10 の元帯 [0.50, 0.70] に戻す (S12 の希釈帯
[0.521, 0.585] は S12 組成の予測値)。

## 7. 教訓 (エポック雑音の再確認)

250 日で固有 OU 間相関 −0.69 を観測 — 実効独立標本 ~6 本での相関推定
(SD ~0.4) の雑音で、2000 日では全成分が設計へ厳密収束した
(corr(msm_i, common) 理論 0.735 vs 実測 0.70-0.75)。**遅い成分の共有検証は
2000 日以上で行う** (S1 の「1 経路 ±15-20%」の相関版)。
