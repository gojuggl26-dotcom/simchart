## 発見

1. **n チャネルは b_n ≥ 0.5 で g ≈ 0.07〜0.09 に飽和する。** 原因はレンジ
   [n_min, n_max] = [0.75, 0.90] 自体: 定常レートは 1/(1−n) に比例し、
   スイングは ×0.68〜×1.7 に構造的に有界 (χ₃ の余地を残す §3.3 の設計の代償)。
   b_n を上げても sigmoid が先に飽和するだけで g は伸びない。
2. **nt_max は 0.897 < n_max = 0.90 で設計どおり有界** (ハード上限 0.97 に遠い)。
3. **n チャネルは危機の深さを自己制限する**: sp_p99 が b_n とともに**低下**
   (66t → 29t)。n_t は全イベント型を増幅する — 取消だけでなく指値補充も増える
   ため、流動性蒸発はむしろ緩む。役割分担が実測で確定:
   **n = 活動度の増幅 (出来高/ボラのクラスタ化)、δ/Δ = 流動性蒸発**。
4. 結合の見込み: L3 (δ=1.0, Δ=0.6〜1.0) の 0.12〜0.32 + n の 0.08 は
   非加算 (§4.3) — S11c で結合状態を再測定して作業点を決める。
